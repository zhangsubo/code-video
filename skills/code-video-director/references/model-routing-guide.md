# 三档制片路线选型与执行细则

根据当前项目的交付目标与运行环境，按以下决策表选择具体执行路径：

## 1. 选型决策速查表

| 场景需求 | 推荐路线 | 预计净耗时 | 外部 API 依赖 | 声音方案 |
|---|---|---:|---|---|
| 快速给 GitHub README / 技术帖补一支丝滑实机演示片 | **路线 A · 极速单模态流** | ~20–25 分钟 | 无（纯本地） | Python 合成 `120 BPM` 氛围乐 + 峰值对齐交互拟音 |
| 制作高信息密度大字报、明暗交替杂志感产品短片 | **路线 B · 瑞士昼夜海报风** | ~35–40 分钟 | 无（纯本地） | Python 合成配乐 + `showwavespic` 网格声波图视觉对拍 |
| 新产品正式发布、众筹页、B站/视频号/YouTube 旗舰宣传片 | **路线 C · 三模态有声大片** | ~40 分钟 | 语音 TTS + 文生图 API | 真人级旁白主时钟 + `-7.5dB` 包络闪避底乐 + 多模态听觉终审 |

---

## 2. 路线 A：极速单模态实机流（Gemini / Claude 范式）

- **上下文穿透**：一次性读取项目的 UI 组件源码（如 SwiftUI / React / Vue 配色常量、圆角半径、真实文案与图标文件），通过小脚本将图标转为 `assets.js`（`window.ASSETS`），避免手写假 UI。
- **连续空间叙事**：采用同一深色毛玻璃桌面舞台内的光学微推拉与焦点切换（`6 幕 × 4.0s = 24.0s`），减少硬切眩晕感。
- **原生看片复核**：若当前 Agent 支持视频/音频文件直读，在 `node render.js --full` 后直接读取 `.mp4` 复查动态模糊与卡点同步。

---

## 3. 路线 B：瑞士国际主义昼夜海报风（Kimi Code 范式）

- **四模块解耦（防长思考单文件截断）**：
  1. `build-assets.js` -> 自动生成 `assets.js`（严禁模型在上下文中手敲几千行 Base64）；
  2. `engine.js` -> 封装 `spring()`、`beat(b)`、`bar(m)` 与 `centerOf(id)`；
  3. `index.html` -> 语义化舞台与 `window.seek(t)`；
  4. `audio_synth.py` + `render.js` -> 合成音轨与并发超采样压片。
- **昼夜呼吸切镜**：痛点大字与收尾金句使用暖白瑞士纸感幕（`#F5F3EE`），实机功能特写切入深邃曜石幕（`#090D16`），严格踩在 `2.0s` 小节重拍上硬切。
- **声波图视觉门禁**：用 FFmpeg `showwavespic=s=1920x360:split_channels=1,drawgrid=w=160:h=180:t=1:c=white@0.25` 导出声波网格图（`24s` 视频每 `160px` 对应 `1 小节`），用视觉检查每个切点是否落在波形重拍峰值上。

---

## 4. 路线 C：三模态有声光学大片（MiniMax 范式）

- **先声夺人（Voice-First Master Clock）**：
  1. 绝不先拍脑袋写死每幕 4 秒！先合成每幕干声（如 `speech-2.8-hd`，开启毫秒级字幕时间戳），转码为 `48000 Hz` WAV 精确测量采样长度；
  2. 每幕前后留出自然气口（前导 `0.38s`、尾韵 `0.45s`，尾幕留 `1.35s` 余韵），自动导出 `timeline.js`（`window.TIMELINE`）锁定全片总帧数与分句时间窗。
- **三明治光学合成（Sandwich Layer Compositing）**：
  - **Layer 0**：AI 生成 3 张**纯光影材质、严禁含任何文字或 UI 框**的 `16:9` 摄影底板（曜石玻璃折射 / 暖光洞石桌面 / 蓝宝石散射），赋予 `scale(1.02 -> 1.07)` 缓慢推镜；
  - **Layer 1**：对比度护栏遮罩（确保前景文字对比度 `> 7:1`）；
  - **Layer 2**：100% 确定性 HTML/CSS/SVG 产品界面与实时靶心光标；
  - **Layer 3**：底部安全区同步高亮字幕胶囊。
- **听觉自愈门禁**：数值检测 `-14 LUFS` 通过不代表没有破音！除校验混音母带与干声包络相关性（目标 `> 0.6`）外，若有音视频理解工具必须对成片执行一次真实听觉审片。
